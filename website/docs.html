EMCL 使用手册

v1.0 · 2026

一、下载与运行

Windows：单文件 EMCL.exe

从下载页获取 EMCL.exe，双击即可。文件内置精简 JRE 与 JavaFX，不需要另外安装 Java；首次启动会自解压数秒，之后正常打开。

全平台：EMCL.jar

需要 Java 17 或更高版本，下载后运行：

java -jar EMCL.jar

Windows 便携目录

EMCL-windows-portable.zip 解压后双击其中的 EMCL.exe，自带运行时，适合不希望每次自解压的用户。

JRE 引导器（可选）

只有 jar、机器上没有 Java 时，可运行 EMCLJavaSetup.exe 静默安装 Temurin JRE 17，完成后自行清理。

二、首次启动

首次启动显示用户协议与免责声明，点「同意」进入主界面。启动器只在用户目录生成 EMCL 配置目录，游戏侧使用 .minecraft。

默认语言为简体中文，默认主题为绿色，可在设置中修改。

三、下载与启动游戏

在「下载」页按正式 / 预览 / 远古 / 愚人节分组浏览并安装版本，可在安装向导中选择加载器。下载源为 BMCLAPI 镜像优先、Mojang 官方兜底，多线程、断点续传，失败自动切换源。

创建实例后选择 Java（也可让启动器自动下载）并点「启动游戏」。启动前会做公平启动检查：识别到作弊客户端、作弊 Mod 或 -javaagent 等注入参数时拒绝启动，原因写入 EMCL/FairPlayBlock.txt，移除后即可正常启动。

四、账号

支持微软正版 OAuth 登录与离线账号。正版登录的授权显示名为 EMCL；客户端 ID 可通过环境变量 EMCL_MS_CLIENT_ID 注入，不内置他人凭据。

五、多人联机

左侧「多人联机」进入陶瓦（Terracotta）。首次使用会下载联机核心（约 8 MiB，走国内镜像）；就绪后可「我想当房主」创建房间生成邀请码，或「我想当房客」输入邀请码加入。联机为 P2P，实际体验与双方网络有关。

六、更新

启动时后台比对 ETQWFD/EMCL 的最新提交。有更新时可选立即更新（jar 版自动下载替换并重启）、忽略此版本或以后再说。单文件 EXE 请重新下载整体替换，不做进程内覆盖。
