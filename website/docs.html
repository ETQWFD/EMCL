EMCL 使用手册

v1.0 · 2026

一、下载与安装

方式 A：EMCL.jar（全平台）

需要 Java 17 或更高版本。下载后执行：

java -jar EMCL.jar

首次启动会自动下载所需 JavaFX 组件（仅一次）。

方式 B：EMCL-windows-portable.zip（Windows 便携版）

解压后双击 EMCL.exe 即可，自带精简 JRE，无需安装 Java。

方式 C：EMCLJavaSetup.exe（可选引导器）

只有 EMCL.jar 而没有 Java 时使用：静默安装 Temurin JRE 17，完成后自动清理自身。

二、首次启动

首次启动会显示用户协议与免责声明，点「同意」后进入主界面。启动器仅在用户目录生成 EMCL 配置目录（及游戏侧 .minecraft），不会生成其他文件夹。

默认界面语言为简体中文，默认主题为绿色，可在「设置」中修改。

三、下载与启动游戏

进入「下载」页可以按 正式 / 预览 / 远古 / 愚人节 分组浏览版本；下载源支持 Mojang 官方与 BMCLAPI 镜像，自动切换、多线程、断点续传，对 403/429 容错。

创建实例后，选择已安装的 Java（可让启动器自动下载），点击「启动游戏」即可。启动前会执行公平启动检查：检测到作弊客户端、作弊 Mod 或 -javaagent 等注入参数时拒绝启动，并把原因写入 EMCL/FairPlayBlock.txt。

四、账号登录

支持微软正版账号（OAuth 完整流程）与离线账号。正版登录授权显示名为 EMCL；客户端 ID 可通过环境变量 EMCL_MS_CLIENT_ID 注入。

五、更新

每次启动后台检查 ETQWFD/EMCL 仓库最新提交。有新版本时弹窗三选：立即更新（jar 版自动下载替换重启）、忽略此版本（不再提示）、以后再说（下次启动再提示）。EXE 版请在「关于」页或官网下载新的便携包整体替换。
