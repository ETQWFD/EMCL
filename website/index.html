EMCL

Java 17 + JavaFX 编写的 Minecraft 启动器。当常见启动器暂时不可用时作为本地入口使用：能下载版本、加载器与资源，支持正版登录和多人联机。

下载 查看源码 使用手册
java -jar EMCL.jar · 需要 Java 17；Windows 可用自带运行时的单文件 EMCL.exe

关于与设置

功能

沿用 HMCL 的能力，品牌与默认配置改为 EMCL。

版本与资源下载

Mojang 官方源与 BMCLAPI 镜像，镜像优先、官方兜底；多线程、断点续传，失败源自动切换，支持 403/429 重试。

加载器

Forge、NeoForge、Fabric、Quilt、OptiFine、Cleanroom 等，随版本安装向导选择。

账号

微软正版 OAuth 登录与离线账号并存，授权显示名为 EMCL；客户端 ID 支持环境变量注入。

多人联机

内置陶瓦（Terracotta）模块，P2P 建房与加入，联机核心走国内镜像下载。

公平启动检查

启动前静态检查作弊客户端、作弊 Mod 与 JVM 注入参数，命中时拦截并写入 EMCL/FairPlayBlock.txt。

更新与公告

启动时比对仓库提交，支持立即更新 / 忽略版本 / 稍后；官网公告在新版本启动时提示一次。

界面

默认简体中文与绿色主题，启动器配置统一放在 EMCL 目录。

跨平台

同一套 Java/JavaFX 代码；Linux、macOS 运行 jar，Windows 提供自带运行时的 EXE。
